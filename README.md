## Menjalankan Program

Pastikan Python sudah terinstal.

### Windows

Tekan **Windows + R**, lalu ketik **cmd** untuk membuka Command Prompt.

~~~bash
python nama_file.py
~~~

### macOS

Tekan **Command + Spasi**, lalu ketik **Terminal** untuk membuka Terminal.

~~~bash
python3 nama_file.py
~~~

**Ganti `nama_file.py` dengan nama file studi kasus yang ingin dijalankan.**
