Project ini berisi 8 studi kasus Python untuk menerapkan logika Boolean dalam berbagai kondisi sederhana.

## Studi Kasus

1. Sistem Seleksi Peserta
2. Sistem Login
3. Peminjaman Buku
4. Sistem Beasiswa
5. Akses Ruangan
6. Pembelian Online
7. Kelulusan Ujian
8. Prioritas Pelayanan

## Materi

- Boolean
- `and`
- `or`
- `if-else`
- Testing


## Menjalankan Program

Pastikan Python sudah terinstall.

Windows:

~~~bash
python nama_file.py
~~~

macOS / Linux:

~~~bash
python3 nama_file.py
~~~

Ganti `nama_file.py` dengan nama file studi kasus yang ingin dijalankan.
