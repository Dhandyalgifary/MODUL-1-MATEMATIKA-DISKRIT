1. Masuk ke browser kalian lalu search website Python atau kunjungi *python.org*
2. Klik bagian *Download* lalu install versi Python yang mendukung perangkat kalian
3. Setelah Python selesai di install klik file Python yang di instal lalu ikuti langkah-langkah yang diberikan Python
